# Project: TG Contact Extractor

### A Professional Telegram Private Chat Contact Extraction Software

Act as a senior Python developer, software architect, UI/UX designer, and security engineer.

I want you to build a complete, professional Windows desktop application named **TG Contact Extractor**.

The application should allow users to connect their own Telegram account, scan their private chat history, collect available contact information, and export the collected data into Excel or CSV files.

This must be a fully working application, not just a UI prototype.

Do not leave placeholder buttons, fake data, or incomplete functionality.

---

# 1. MAIN OBJECTIVE

Build a Windows desktop application that extracts available user information from all accessible private conversations of the authenticated Telegram account.

The application should include:

1. Saved contacts.
2. Non-saved contacts.
3. Existing private conversations.
4. Archived private conversations.
5. Old private conversations accessible through Telegram.
6. Users who have usernames.
7. Users who have phone numbers.
8. Users who have neither a visible username nor a visible phone number.

IMPORTANT:

* Only scan private one-to-one conversations.
* Do not extract group members.
* Do not extract channel members.
* Do not extract bots.
* Do not extract information that Telegram does not make available to the authenticated account.
* Never attempt to bypass Telegram privacy restrictions.

# 4. TELEGRAM ACCOUNT CONNECTION

Create a secure Telegram login system.

Login workflow:

Step 1:
Ask the user to enter:

* Telegram API ID
* Telegram API Hash
* Phone Number with country code.

Step 2:
Send Telegram login code using the official Telegram authentication process.

Step 3:
Display an OTP input field.

Step 4:
Verify the OTP.

Step 5:
If two-step verification is enabled, request the 2FA password.

Step 6:
Successfully authenticate and connect the account.

Requirements:

* Use Telethon.
* Use the official Telegram API.
* Support session persistence.
* Avoid asking for OTP every time if the existing session is valid.
* Provide a Disconnect Account option.
* Provide a Logout option.
* Handle invalid OTP and incorrect passwords.
* Handle expired sessions.
* Never log or expose OTP or 2FA passwords.
* Store session files securely on the user's computer.
* Never upload session files to external servers.

API ID and API Hash should be entered by the user.

Do not hardcode API credentials.

Provide a link to Telegram's official API development page:
https://my.telegram.org/apps

# 5. CONTACT EXTRACTION ENGINE

After successful login, show a dashboard.

Add a button:

START EXTRACTION

When clicked, scan accessible private one-to-one conversations.

Include:

* Regular private conversations.
* Archived private conversations.
* Existing private chat dialogs.
* Saved contacts.

Use Telegram's available dialog and contact APIs.

Important implementation details:

* Use Telethon's dialog iteration functionality.
* Identify private User entities.
* Exclude groups, channels, bots, and the authenticated user's own account.
* Avoid extracting duplicate users.
* Handle deleted or inaccessible users gracefully.
* Do not assume that every Telegram contact has a phone number.
* Do not scrape group participants.
* Do not attempt to recover hidden phone numbers.

For each eligible user, collect available information.

* Invalid API ID.

* Deleted Telegram accounts.
* Missing username.
